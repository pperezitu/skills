# Backend Expert Skill

Expert backend engineer for Node.js, Express, and NestJS projects providing architectural guidance, production-ready code, and comprehensive testing strategies.

## Overview

This skill provides:
- **Clarifying questions** — Understands context before proposing solutions
- **Architecture proposals** — SOLID principles, CQRS, DDD, Event-Driven Design with trade-off analysis
- **Production code** — Clean, testable implementations with inline documentation
- **Comprehensive tests** — Jest tests covering happy paths, edge cases, and error scenarios
- **Token-efficient guidance** — Concise, actionable recommendations

## When to Use

**Automatic activation:**
- Detects NestJS projects (nest.js, @nestjs in package.json)
- Detects Express projects (express in package.json)

**Manual invocation:**
- Backend architecture decisions
- Service design and implementation
- Database patterns and queries
- API endpoint design
- Error handling and validation strategies
- Testing and test coverage
- DevOps and deployment concerns
- Design patterns (Factory, Strategy, Observer, etc.)
- SOLID principles application

## Workflow

The skill follows a 4-phase approach:

1. **Clarify** — Ask clarifying questions about requirements, constraints, and trade-offs
2. **Propose** — Present architecture options with pros/cons
3. **Implement** — Generate production-ready code with explanations
4. **Test** — Provide comprehensive test suites
