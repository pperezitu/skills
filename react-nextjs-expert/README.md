# React & Next.js 13+ Expert Skill

Un skill especializado para proporcionar guidance experto en React 18+ y Next.js 13+ (App Router), con énfasis en patrones modernos, TypeScript y optimización de performance.

## Características

- **Expert Guidance**: Recomendaciones de arquitectura y patrones basadas en mejores prácticas actuales
- **Code Review**: Análisis detallado de código con sugerencias de mejora
- **Performance Optimization**: Identificación de cuellos de botella y estrategias de optimización
- **TypeScript First**: Foco en type safety y patterns de TypeScript
- **Modern Patterns**: Server Components, Suspense, Error Boundaries, App Router patterns
- **React 18+ Features**: Aprovecha las características más recientes de React

## Qué Puedes Hacer con Este Skill

### 1. Arquitectura y Diseño
- Estructura de proyectos Next.js 13+
- Organización de layouts, routes y componentes
- Patrones de state management
- Decisiones Server Components vs Client Components

### 2. Code Review
- Revisar componentes React existentes
- Identificar problemas de performance
- Sugerir mejoras de TypeScript
- Mejorar maintainability

### 3. Problem Solving
- Debuggear issues de rendering
- Optimizar performance
- Entender patrones y best practices
- Aprender sobre nuevas características de React/Next.js

### 4. Educación
- Entender cuándo usar diferentes hooks
- Aprender sobre memoización (React.memo, useMemo, useCallback)
- Dominar Server Components y Suspense
- Implementar patrones avanzados

## Cuándo Activarse

El skill se activará cuando:
- Estés trabajando en un proyecto React o Next.js
- Necesites arquitectura o consejos de performance
- Pidas código review o refactoring
- Hagas preguntas sobre React 18+ o Next.js 13+
- Menciones componentes, hooks, rutas o patrones

## Principios del Skill

1. **Explicar el por qué** - No solo qué hacer, sino por qué es la mejor opción
2. **Basado en contexto** - Toma en cuenta tus restricciones y goals
3. **Data-driven** - Recomienda medición antes de micro-optimizaciones
4. **Moderno** - Next.js 13+ App Router como default, React 18+ patterns
5. **TypeScript first** - Enfoque en type safety
6. **Práctico** - Ejemplos que puedes usar directamente

## Compatibilidad

- **React**: 18+
- **Next.js**: 13+ (recomendado 14+)
- **TypeScript**: Recomendado, pero no requerido
- **Node.js**: 18+

## Notas

Este skill es más efectivo cuando:
- Tienes un proyecto React/Next.js real que mostrar
- Describes el contexto y restricciones
- Estás abierto a aprender nuevos patrones
- Validas recomendaciones con tu equipo
